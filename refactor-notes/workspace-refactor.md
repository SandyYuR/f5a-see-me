# 布局工作台交互重构

本轮按「电脑浏览器编辑，手机验证」设计，已直接实现到当前项目。

## 操作方式

- 顶部选择布局和子模式，导入、导出、源码入口常驻。
- 点击键盘预览或排列区的按键，右侧显示当前按键属性，两处同步高亮。
- 主／副字符、标签、宽度权重、行高可以直接修改。离开输入框或按 Enter 应用；无效输入保留在表单中并提示原因。
- 用上一键／下一键连续编辑；复制、左右移动、删除支持已有撤销／重做和草稿保存。
- 按键类型、事件、显示文本映射、颜色和合成态仍通过「完整编辑」进入原有编辑器。
- JSON 和预览参数按需展开。JSON 仍与可视化布局双向同步；CodeMirror 按需加载，离线时使用 textarea。
- 手机端使用单列布局，选键后滚动到属性区，并提供返回预览按钮。长行仅在排列区内部横向滚动。

## 同时修复的问题

- 编辑输入框后立即点击另一个键，避免重绘移除点击目标导致第一次点击失效。
- 预览独立的分体变体时，点击按键切到对应的分体排列，不再误写普通排列。
- 布局切换、导出、分享和写入输入法会先校验待应用的按键输入。
- JSON 编辑或撤销导致数据变化时同步刷新属性区。
- 导入失败在工作台直接提示，避免错误藏在折叠的 JSON 区域。
- 触屏行内选键不再沿用模态弹窗的吞点击标记。

## 实现边界

`js/layout-workspace.js` 管理选中态、属性编辑、导航和工作台交互；`workspace.css` 管理新的页面布局。`app.js` 仅添加接入点并复用已有规范化、预览、导入导出、撤销和存储逻辑。没有引入构建工具或新的运行时依赖。

布局导出格式及复杂按键配置保持兼容。快捷修改从完整按键对象复制后更新字段，保留宏事件、显示文本映射和合成态；选中态不写入导出数据。

## 验证

- 现有 Node 测试：**115 / 115 通过**。
- 预置资源比对所需的 18 份输入法资源从 `SandyYuR/fcitx5-android` 的 `fx-rime-only` 分支读取，主题、图标及符号资源比对通过。资源只用于验证，没有修改项目内预置数据。
- `tests/workspace-browser.py`：Chromium 实际点击、填写、导入、导出、拖动及触控全部通过。
- 浏览器覆盖：连续选键、错误校验、尺寸默认值恢复、复制移动删除、撤销重做、完整编辑的保存与取消、五个页签、JSON 双向同步、分体变体、嵌套数据保留、下载内容、刷新后草稿恢复。
- 窄屏与桌面检查：360、390、768、1024、1440、1920px，没有页面横向溢出；无页面脚本异常或重复 DOM ID。
- 另行确认在线 CodeMirror 正常加载，源码修改能立即反映到属性区。
- JavaScript 语法检查、`git diff --check` 通过。

未连接 Android 真机，本轮不包含 IME API 写入和真机渲染验收。

## 本地运行与复现

在项目根目录执行：

```sh
python -m http.server 8080
```

浏览器打开 `http://localhost:8080`。

```sh
# FXR_ASSETS 指向输入法仓库中的 bundled 目录
FXR_ASSETS=/path/to/fcitx5-android/app/src/main/assets/bundled node --test tests/*.test.cjs

# 需要 Python Playwright 和 Chromium；测试自行启动临时 HTTP 服务
python tests/workspace-browser.py
```

浏览器测试可用 `CHROMIUM_PATH` 指定浏览器，`F5A_SHOTS` 指定截图目录；测试使用独立浏览器上下文，不读取现有草稿。
