# 工作区对齐 Foxy

## 2026-10-31 响应式与启动修订

预览在所有工作区断点使用同一个渲染宽度，行高、字形、圆角和间距随有效预览宽度调整。移除右侧属性窗时不会再只拉宽按键。新增 980/981 与 1080/1081 px 边界的浏览器几何检查；本次本地浏览器已确认 1440 和 980 px 下首排均为 576 px。

点选预览按键后焦点进入属性字段，Escape 通过已有的未保存修改提示退出并回到原按键。逐键高亮每轮只验证一次布局，输入产生的预览更新合并到下一帧，草稿写入做 200 ms 合并并在离页时补写。

二维码与 ZIP 的原有固定版本依赖改为按需加载。组件请求有 10 秒超时，失败后可重新执行操作重试；普通编辑和 JSON 导出不等待 CDN。新增加载去重、超时与重试测试，本次 Node 共 118 项通过。完整浏览器用例由 `Editor checks` 工作流在 `site` 推送和 PR 中执行，其结果以对应提交的 Actions 为准。下面原有截图及验证记录对应此前工作区改造。

参考 [foxy-see-me 的工作区操作](https://github.com/SandyYuR/foxy-see-me/blob/main/docs/workspace-editing.md)，按照电脑编辑、手机验证的使用方式调整。保留 fcitx5-android 的布局格式、按键能力和导入导出协议。

## 页面与操作

- 全局键盘预览和等高属性窗放在页面上方；桌面功能页签在下方，手机页签在预览之前。各类文件的导入、导出和 IME 操作留在所属页签。
- 恢复紧凑标题、原有配色、卡片和页签样式，取消上一版的大标题和点阵画布。主分栏默认展开，按固定 ID 记住折叠状态。
- 点击预览按键进入属性窗；点击排列区按键打开完整编辑弹窗。预览上方可以切换布局，状态模拟和外观设置分别展开。
- 属性窗修改先进入独立草稿并更新预览；应用才写入布局，取消会同时撤回字段和左右移动。一次应用对应一次撤销。
- 切换按键、布局、功能页签，打开完整编辑或执行文件操作时，未应用的按键修改可选择继续编辑、放弃或应用。拖动排列前也需先处理草稿。
- 切换分体／合成预览会暂存按键草稿，重新选择原排列中的原按键可以继续。刷新恢复时须匹配原排列，旧草稿不会套用到已经变化的按键上。
- 属性窗提供字符、标签、简单显示文本和尺寸编辑；映射式显示文本、按键类型、宏、划动、颜色和合成态使用原有完整编辑器。快捷编辑保留未改动的嵌套字段。
- 排列区支持复制整行；副本独立，支持撤销。文本编辑布局不提供整行复制。
- 手机属性窗为底部面板，当前按键预览和应用／取消按钮固定，字段区独立滚动。

## 布局 JSON

布局 JSON 默认展开，输入、格式化、修复均只修改草稿。点击“应用 JSON”后更新布局；“还原 JSON”恢复已应用内容。无效或尚未写完的文本单独缓存，刷新不自动提交，也不会被可视化编辑覆盖。

导出布局、分享或保存到 IME 前检查未应用的布局 JSON，可返回编辑、使用已应用内容或应用 JSON 后继续。其他文件页保留各自现有的编辑方式。

## 工具栏预览修复

- 选择、导入和修改图标主题后主动刷新预览，并将同一帧内的更新合并。
- IME 文件图标加载成功后立即刷新工具栏。并发请求去重，缓存区分主题、槽位和文件路径；旧主题的迟到响应不会覆盖当前槽位。重新读取 IME 时使旧缓存和请求失效。
- 符号、Emoji、颜文字预览包含键盘工具栏和可切换的状态区。工具栏与符号内容使用独立容器，切换符号分组不会清除工具栏；状态区展开保持键盘区高度。

## 实现与验证

`js/layout-workspace.js` 负责按键草稿、选择、离开提示和属性窗；`workspace.css` 负责工作区样式。`js/app.js` 接入草稿预览、显式布局 JSON 应用及图标刷新。没有引入运行时依赖或构建步骤。

```sh
FXR_ASSETS=/path/to/fcitx5-android/app/src/main/assets/bundled node --test tests/*.test.cjs
python tests/workspace-browser.py
```

- Node：115 项测试通过，包括与输入法内置主题、图标、符号资源的比对。验证资源来自 `SandyYuR/fcitx5-android` 的 `fx-rime-only` 分支，未修改项目预置文件。
- Chromium：验证草稿预览与显式提交、离开提示、移动取消与单步撤销、刷新恢复、JSON 导出选择、独立分体、嵌套字段保留、整行复制、拖动、触屏弹窗及属性窗。
- 工具栏回归：切换内置主题、导入与编辑图标、异步文件图标完成、请求去重、迟到响应、同槽位换文件、三类符号及分组切换、工具栏／状态区开关。
- 检查 360、390、768、1024、1440、1920px 宽度及手机 480px 短视口，无页面横向溢出或脚本异常。
- 浏览器回归在禁用外部 CDN 时使用 textarea，另行检查在线 CodeMirror 的草稿与应用流程。
